# SEskill

Agent Skill, который превращает проект в компактную визуальную схему: создаёт JSON для SEditor и автономный HTML-ярлык со встроенными схемой и редактором. Ярлык открывается в браузере без сервера.

[English README](README.md) · [SEditor](https://github.com/Fluttershy174PUNK/SEditor)

## Установка

**Место установки определяет, где агент находит скилл, а не куда он записывает результат.** При запуске агента из проекта SEskill изучает этот проект и сохраняет схемы, ярлыки и управляемый рантайм в его `SEditor/` (или в любой другой каталог, который укажет пользователь). Глобальная установка не перенаправляет файлы в каталог самого скилла.

### Pi

Pi поддерживает установку пакетом и установку каталога скиллов ([обнаружение скиллов](https://github.com/badlogic/pi-mono/blob/main/packages/coding-agent/docs/skills.md), [установка пакетов](https://github.com/badlogic/pi-mono/blob/main/packages/coding-agent/docs/packages.md)):

| Область | Команда | Поведение Pi |
| --- | --- | --- |
| Проектная (рекомендуется для команды) | `pi install --local git:github.com/Fluttershy174PUNK/SEskill` | Записывает пакет в `.pi/settings.json`; проектные ресурсы загружаются после выдачи доверия проекту. |
| Личная/глобальная | `pi install git:github.com/Fluttershy174PUNK/SEskill` | Записывает пакет в `~/.pi/agent/settings.json`; доступен из разных проектов. |

Скилл расположен в стандартном каталоге `skills/seditor/`, который Pi обнаруживает при установке Git-пакета. Альтернатива — скопировать только каталог скилла: в проектный `.agents/skills/seditor/` или личный `~/.agents/skills/seditor/`. Pi обнаруживает скиллы в обоих местах. Явный вызов: `/skill:seditor ...`.

### Другие совместимые агенты

Скопируйте каталог `skills/seditor/` из этого репозитория в поддерживаемое агентом место; конечная папка должна называться `seditor`. Каталоги сверены с документацией [Claude Code](https://code.claude.com/docs/en/skills) и [GitHub Copilot CLI](https://docs.github.com/en/copilot/how-tos/copilot-cli/customize-copilot/add-skills):

| Агент | В проекте | Личная/глобальная установка |
| --- | --- | --- |
| Claude Code | `.claude/skills/seditor/` | `~/.claude/skills/seditor/` |
| Codex | `.agents/skills/seditor/` | Личный путь проверьте в документации Codex для установленной версии; здесь подтверждён только проектный. |
| GitHub Copilot CLI | `.github/skills/seditor/` или `.agents/skills/seditor/` | `~/.copilot/skills/seditor/` или `~/.agents/skills/seditor/` |

Например, после клонирования репозитория в `/путь/к/SEskill`, из корня проекта установите для Claude Code: `mkdir -p .claude/skills && cp -R /путь/к/SEskill/skills/seditor .claude/skills/seditor`. Для Codex или каталога `.agents` у Copilot используйте `.agents/skills` как назначение. Для личной установки укажите домашний каталог агента, например: `mkdir -p ~/.claude/skills && cp -R /путь/к/SEskill/skills/seditor ~/.claude/skills/seditor`.

Проектные установки удобнее делить с командой и версионировать. Личные/глобальные удобны для повторного использования; результат при этом всё равно записывается в `SEditor/` активного проекта.

Запускайте агента из каталога проекта, чтобы скилл изучил и изменил именно его. Затем попросите создать схему, например:

```text
/seditor нарисуй поток авторизации
/seditor создай карту экранов оформления заказа
```

Навык изучит проект и создаст `SEditor/<type>-<topic>.json` и HTML-ярлык с таким же именем. HTML содержит схему и редактор — откройте его для правки диаграммы; выделите узел и используйте `Ctrl/Cmd+C/V/X/Z` для копирования, вставки, вырезания и отмены. Node нужен только для генерации и проверки файлов.

## Структура вывода

Всё, что создаёт навык, лежит в одной папке в корне проекта — `SEditor/` по умолчанию или в каталоге, который укажет пользователь:

```text
SEditor/
├── SEditor.html              # автономная копия редактора — откройте для ручной правки схем
├── app/                      # управляемый рантайм SEditor (контрольные суммы, править нельзя)
├── <type>-<topic>.json       # схема
└── <type>-<topic>.html       # ярлык: открывает схему двойным кликом, без сервера
```

Проекты, созданные скиллом ≤ 0.6, сохраняют свой `.SEditor/` — передавайте его скриптам явно.

## Формат и совместимость

Встроенный пример короткий и читаемый: используйте его как образец, не копируйте значения по умолчанию, которые редактор проставляет сам. Навык создаёт компактный JSON SEditor v1. Старые схемы без версии и v1 поддерживаются; неизвестные будущие версии нельзя понижать. Значения по умолчанию и вычисляемые геометрические поля опускаются. См. каноническое [описание формата](skills/seditor/references/schema-format.md).

## Проверка

```bash
node skills/seditor/scripts/validate-project.mjs .
bash verify.sh
```

`verify.sh` проверяет пакет навыка, контрольные суммы и синхронизацию рантайма, автономные ярлыки и совместимый backend, схемы и механические eval-сценарии. Нужен соседний checkout SEditor либо переменная `SEDITOR_ROOT` с его путём.
