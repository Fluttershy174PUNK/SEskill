# SEskill

Agent Skill, который превращает проект в компактную визуальную схему: создаёт JSON для SEditor и автономный HTML-ярлык со встроенными схемой и редактором. Ярлык открывается в браузере без сервера.

[English README](README.md) · [SEditor](https://github.com/Fluttershy174PUNK/SEditor)

## Установка

**Рекомендуется: установить навык в репозиторий проекта** — так вся команда использует одну версию. Для Pi скопируйте пакет в проектный каталог навыков:

```bash
mkdir -p .agents/skills
cp -R /путь/к/SEskill/skills/seditor .agents/skills/seditor
```

Pi обнаруживает `.agents/skills/` в проекте; для явного вызова используйте `/skill:seditor ...`. Другие совместимые агенты могут использовать собственный проектный каталог (например, `.claude/skills/seditor` или `.github/skills/seditor`); копируйте туда ту же папку `skills/seditor/`, сохраняя имя `seditor`.

**Необязательно: глобальная установка в Pi** — для личного использования в разных проектах:

```bash
pi install git:github.com/Fluttershy174PUNK/SEskill
```

Проектная установка предпочтительна для общих настроек и версионирования; глобальная удобна для личного повторного использования.

Затем попросите агента создать схему, например:

```text
/seditor нарисуй поток авторизации
/seditor создай карту экранов оформления заказа
```

Навык изучит проект и создаст `.SEditor/<type>-<topic>.json` и HTML-ярлык с таким же именем. HTML содержит схему и редактор — откройте его для правки диаграммы; выделите узел и используйте `Ctrl/Cmd+C/V/X/Z` для копирования, вставки, вырезания и отмены. Node нужен только для генерации и проверки файлов.

## Формат и совместимость

Встроенный пример короткий и читаемый: используйте его как образец, не копируйте значения по умолчанию, которые редактор проставляет сам. Навык создаёт компактный JSON SEditor v1. Старые схемы без версии и v1 поддерживаются; неизвестные будущие версии нельзя понижать. Значения по умолчанию и вычисляемые геометрические поля опускаются. См. каноническое [описание формата](skills/seditor/references/schema-format.md).

## Проверка

```bash
node skills/seditor/scripts/validate-project.mjs .
bash verify.sh
```

`verify.sh` проверяет пакет навыка, контрольные суммы и синхронизацию рантайма, автономные ярлыки и совместимый backend, схемы и механические eval-сценарии. Нужен соседний checkout SEditor либо переменная `SEDITOR_ROOT` с его путём.
